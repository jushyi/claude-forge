# Security

Report vulnerabilities privately through GitHub's private vulnerability reporting: the **Report a vulnerability** button on this repo's Security tab. Don't open a public issue for one.

Forge's own sessions run Claude Code with `bypassPermissions`, so reports about escaping the guard hook (`hooks/forge-guard.sh`), about `port` changing files it should not, and about credential handling are especially useful.

There is no response-time promise.
